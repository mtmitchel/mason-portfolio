## Field guidance

- Transcribe file names, page names, batch labels, selected ranges, and
  frame/node IDs only from the reviewed Figwright batch. Never infer a missing
  identifier.
- Keep the visual description observable. Use `unknown`, `unreadable`, or
  `unverified` when the batch does not establish a detail.
- Treat likely project, chronology, and contribution relationship as working
  hypotheses. Check them against the active chronology, contribution map, and
  project crosswalk before strengthening them.
- Record editability and provenance only when the reviewed evidence establishes
  them. Appearance alone does not prove either.
- Provisional value is a comparison note, not a final disposition, public
  claim, or asset selection. Final judgment waits for complete page-and-batch
  coverage.
- Use follow-up need for the exact unresolved check. A follow-up note does not
  authorize a Figma edit, export, mockup, or site change.
