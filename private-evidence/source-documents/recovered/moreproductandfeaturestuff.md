Glossaries are available for Text translation and Document

A glossary consists of entry pairs of source text and target
text
It can include one or more language pairs
Glossary entries can be created manually, by DeepL
suggestions or by CSV upload
Multiple glossaries can be created (see Requirements &
Limitations)
Only one glossary can be selected for translation at a time
Glossary terms are automatically adapted to fit into the translation (no search & replace). There is no need to enter plural
forms or inflected verbal forms.
For free users, glossary entries are stored locally (on the user’s device)
API glossaries are distinct from glossaries in the web translator/desktop apps.
Glossaries used via API can't be used on DeepL web and DeepL desktop apps and vice versa.

Single Sign-On (SSO) enables users to log into multiple
applications with the same credentials.
With SSO, business customers have a centralized and secure
authentication process for all of the applications they use.
Availability
A team licence with a minimum of 50 licences is required.

for all team members

SCIM is not yet supported
Users will be redirected to log in with their credentials via the
companies identity provider (company specific setup how this is
handled)

SSO Setup
Customers have to request a SSO domain
Team administrators set up SSO in their DeepL account

SAML v2.0

created.
User de-provisioning requires manual action
The user needs to be removed from the the security group in the identity provider
The user’s DeepL account must be removed
