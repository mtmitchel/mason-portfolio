Differences between DeepL plans

Okay, I can break down the differences between the plan tiers for each DeepL product based on the provided documents.

**DeepL API Pricing**

DeepL API offers three plans:

*   **DeepL API Free:**
    *   **Cost:** Free
    *   **Data Security:** Access to all features, access to REST API
    *   **API Keys:** Up to 2
    *   **Character Limit:** 500,000 characters/month
    *   **Glossaries:** 1,000 (for specific languages)
    *   **Other Features:** Upgrade to Pro anytime
    *   **Exclusions:** CAT tool integration, web translator

*   **DeepL API Pro:**
    *   **Cost:** $5.49/month + usage-based price ($25.00 per 1,000,000 characters)
    *   **Data Security:** Maximum data security
    *   **API Keys:** Up to 25
    *   **Character Limit:** No volume restrictions, pay as you go
    *   **Glossaries:** 1,000 (for specific languages)
    *   **Other Features:** Prioritized execution of requests, cost control settings
    *   **Exclusions:** CAT tool integration, web translator

*   **DeepL API for Business:**
    *   **Cost:** Custom pricing available
    *   **Data Security:** Maximum data security (includes everything in DeepL API Pro)
    *   **API Keys:** Custom (includes everything in DeepL API Pro)
    *   **Character Limit:** Custom (includes everything in DeepL API Pro)
    *   **Glossaries:** Custom (includes everything in DeepL API Pro)
    *   **Other Features:** Custom feature limits, payment by invoice, eligible for a Customer Success Manager and onboarding planning and support

**DeepL Write Pricing**

DeepL Write offers three plans:

*   **Free:**
    *   **Cost:** $0
    *   **Data Security:** Not specified
    *   **Text Improvements:** Limited
    *   **Alternatives:** Not specified
    *   **Writing Styles:** Not specified

*   **DeepL Write Pro:**
    *   **Cost:** $10.99/user/month (billed annually)
    *   **Data Security:** Maximum data security
    *   **Text Improvements:** Unlimited
    *   **Alternatives:** Unlimited use
    *   **Writing Styles:** Unlimited use

*   **DeepL Write for Business:**
    *   **Cost:** Contact sales (for teams with 50+ users)
    *   **Data Security:** Maximum data security
    *   **Text Improvements:** Unlimited
    *   **Alternatives:** Unlimited use
    *   **Writing Styles:** Unlimited use
    *   **Other Features:** Team administration, Single sign-on (SSO)

**DeepL Translator Pricing**

DeepL Translator offers four plans:

*   **Free:**
    *   **Cost:** Free
    *   **Users:** 1
    *   **Text Translation:** Limited
    *   **File Translations:** 3 non-editable files/month
    *   **File Size:** Up to 5 MB
    *   **Glossaries:** 1 glossary, 10 entries

*   **Starter:**
    *   **Cost:** $8.74/user/month (billed annually)
    *   **Users:** Up to 5
    *   **Data Security:** Maximum
    *   **Text Translation:** Up to 1 million characters/user/month
    *   **File Translations:** 5 editable files/user/month
    *   **File Size:** Up to 10 MB
    *   **Glossaries:** 1 glossary, unlimited entries

*   **Advanced:**
    *   **Cost:** $28.74/user/month (billed annually)
    *   **Data Security:** Maximum
    *   **Text Translation:** Unlimited
    *   **File Translations:** 20 editable files/user/month
    *   **File Size:** Up to 20 MB
    *   **Glossaries:** 2,000 glossaries, unlimited entries, shared with team
    *   **Other Features:** Single sign-on (SSO), CAT tool integration

*   **Ultimate:**
    *   **Cost:** $57.49/user/month (billed annually)
    *   **Data Security:** Maximum
    *   **Text Translation:** Unlimited
    *   **File Translations:** 100 editable files/user/month
    *   **File Size:** Up to 30 MB
    *   **Glossaries:** 2,000 glossaries, unlimited entries, shared with team
    *   **Other Features:** Single sign-on (SSO), CAT tool integration

*   **Enterprise:**
    *   **Cost:** Contact sales (available from 1,000 seats)
    *   **Includes:** Market-leading translation accuracy, AI-powered business writing at scale, integration, global security and compliance, flexible pricing.

**Key Differences**

*   **Data Security:** The paid plans for DeepL API and DeepL Write offer maximum data security. DeepL Translator offers maximum data security on its paid plans (Starter, Advanced, Ultimate).
*   **Usage Limits:** Free plans have limitations on usage (characters, files, glossaries). Paid plans offer higher limits or unlimited usage, depending on the tier.
*   **Features:** Higher-tier plans offer more advanced features like team administration, SSO, custom glossaries, and CAT tool integration.
*   **Pricing:** Prices vary based on the features included and whether you choose monthly or annual billing.

**In summary,** DeepL offers a range of plans to suit different needs and budgets, from individual users to large enterprises. The free plans are a good starting point for basic translation or writing assistance, while the paid plans provide more features, higher usage limits, and enhanced data security for professional or business use.
