# Monetization pricing-page exports

Private PNG and PDF exports from the historical DeepL Monetization Figma file.
The set covers Translator, Translator and Write bundles, Write, Voice, API, and
one separate Voice copy-island frame.

The `@2x` PNG files are the higher-resolution Translator and Bundles exports.
The other PNG files are 1x companions to their matching PDFs. The Voice
copy-island pair came from an unnamed Figma frame and was renamed locally for a
clear filesystem label; its contents were not changed.

These files are private source evidence. Selected public copies live under
`site/public/work/pricing-evolution/` and are recorded in
[`../../../portfolio-asset-manifest.json`](../../../portfolio-asset-manifest.json).
