# DeepL Product Portfolio and Evolution, 2023–Present

## Executive summary

DeepL’s portfolio is best understood today as a **language-AI platform** with five current top-level product families: **DeepL Translator**, **DeepL Write**, **DeepL Voice**, **DeepL API**, and **DeepL Integrations**. Around those sit two important cross-cutting layers: an **enterprise/admin layer** for security, access, and governance, and a **customization layer** that DeepL now explicitly brands as **Customization Hub**. That architecture is visible in DeepL’s current site navigation, product pages, enterprise pages, and help center structure. citeturn18search13turn17search2turn35search3turn15search1

The biggest portfolio changes since early 2023 were these. In **January 2023**, DeepL launched **DeepL Write** in beta as a distinct writing product. In **April 2024**, it launched **DeepL Write Pro**, moving writing from a free experiment into a paid business offer. In **November 2024**, DeepL launched **DeepL Voice** with two user-facing offerings, **Voice for Meetings** and **Voice for Conversations**. Through **2025**, DeepL expanded the API from translation-only positioning toward a broader platform that includes **Write**, then **Voice API**, and later a larger customization surface. In **late 2025 and 2026**, DeepL introduced or formalized **Marketplace**, **Customization Hub**, **Translation Flow**, **Clarify**, and **AI connectors/MCP-based agent connections**, which collectively make DeepL less like a single translator app and more like a governed workflow platform for multilingual work. citeturn8search6turn40search4turn40search16turn20search8turn10view0turn8search1turn8search0turn40search11turn38view0

Several names that look like “products” are not best treated as stand-alone products. **Clarify** is best supported as a **Translator feature**, not a separate subscription. **Translation Flow** currently behaves like both a **marketed workflow layer** within Translator and a **sales-led add-on/feature package** for Business/Enterprise customers. **Customization Hub** is a **capability family/control layer**, not a separately purchased consumer app. **Marketplace** is a **partner/integration storefront**, not a translation engine. **Write Pro** is a **paid version or add-on path for Write**, not a separate company platform. **AI connectors** are an **integration channel** that exposes existing DeepL account capabilities to ChatGPT, Claude, and Microsoft Copilot via MCP, not a new core model family. citeturn13search2turn26search0turn15search10turn15search12turn39view0turn24search2turn38view0turn38view3

The largest source of ambiguity today is **naming and packaging**, especially around **DeepL Pro**, **API Free/API Pro/API Developer/API Growth**, and the overlap between **web features**, **desktop/mobile features**, **sales-led enterprise features**, and **API capabilities**. Current support pages say **API Free** and **API Pro** can no longer be purchased, while current technical and legal materials still refer to those names for grandfathered plans, hostnames, and entitlement logic. The most defensible interpretation is that the **current buy path** centers on **API Developer**, **API Growth**, and **Enterprise API**, while **API Free** and **API Pro** remain legacy or grandfathered terms that still appear in docs and UI. citeturn20search0turn20search2turn20search6turn18search3turn10view0

## Product families and architecture

### Product-family profiles

**DeepL Translator.**  
**Classification:** product family. **Earliest verified availability in scope:** pre-2023, with continuous expansion through 2026. **Current lifecycle:** active, generally available. **Primary job:** translation of text, files, images, and selected speech workflows. **Principal capabilities:** text translation, document translation, image translation, formality controls, dictionary/alternatives, saved translations, and access to customization assets such as glossaries, style rules, translation memories, and style profiles. **Main inputs/outputs:** typed or pasted text, uploaded files, selected webpage text, images, and meeting captions in; translated text, translated files, and captions out. **Surfaces:** web, desktop, mobile, browser extensions, Microsoft add-ins, Google Docs/Slides/Gmail via extension, and indirectly through integrations and workflow products. **Important changes since 2023:** Clarify was added in 2025, the next-generation LLM was publicized in 2024, and the product was reframed in 2026 as an “AI-first multilingual platform” connected to Translation Flow and enterprise review workflows. **Limitations/conditions:** some controls are plan-gated; not every feature exists on every surface. **Unresolved question:** DeepL markets Translator as a single product, but some enterprise materials increasingly blur the line between “Translator” and the broader platform shell. citeturn28view0turn13search2turn31search3turn11search17turn12search7

**DeepL Write.**  
**Classification:** product family. **Earliest verified availability:** January 17, 2023, when DeepL launched the beta version of Write. **Current lifecycle:** active; free and paid paths exist. **Primary job:** improve grammar, phrasing, tone, and style rather than translate. **Principal capabilities:** corrective rewriting, rephrasing, style/tone adaptation, “terms to never edit,” style rules, and integrated use in browser and document surfaces. **Main inputs/outputs:** text in; corrected or rephrased text out. **Surfaces:** website, desktop apps, mobile apps, browser extensions, Google Docs/Slides/Gmail, Microsoft Word, and API for Write. **Packaging:** Write Pro exists as a stand-alone paid writing product or add-on path; DeepL’s help center explicitly says the **Write Pro add-on** can be attached to Translator plans that do not already include it, and that API access is separate. **Important changes since 2023:** free beta launch in 2023; Write Pro launch in 2024; API for Write and broader API integration in 2025; style/customization integration and broader security/governance positioning by 2025–2026. **Unresolved question:** DeepL sometimes uses “Write Pro” as if it were a full product and sometimes as if it were an add-on/bundle component; the best-supported interpretation is “paid Write entitlement,” with packaging dependent on plan context. citeturn8search6turn40search12turn40search4turn24search2turn32search13turn28view1turn20search8

### Product architecture and relationships

DeepL’s present architecture is not a loose list of apps. It is a layered system:

1. **Core capability families:** Translator, Write, Voice, API.  
2. **Access channels and surfaces:** web, desktop, mobile, extensions, Microsoft add-ins, meeting surfaces, partner apps, direct API.  
3. **Control layer:** Customization Hub assets such as glossaries, style rules, style profiles, and translation memories.  
4. **Workflow layer:** Translation Flow and certain integrations.  
5. **Governance layer:** roles, SSO/SCIM, MFA, analytics, audit logs, BYOK, network controls, domain capture, AI connector controls. citeturn18search13turn8search1turn26search0turn35search3turn33search1turn34search0

### Enterprise and governance layer

DeepL’s enterprise/governance layer is more substantial than its old public reputation as “just a translator” suggests. Team administration includes **team admins**, **customization admins**, and **API admins**; group management; license assignment; document-translation quota controls; team analytics; optional visibility controls for individual-user usage data; and control over whether unlicensed but logged-in users may reach the free versions of Translator and Write. citeturn33search1turn34search0turn34search1turn34search11turn33search2

For authentication and identity, DeepL supports **SSO with SAML and OpenID Connect**, **SCIM provisioning**, **domain capture**, and **MFA for non-SSO users**. Domain capture and network-access restrictions are higher-end capabilities that help control who in an organization can create or use DeepL accounts, while SCIM and SSO bring DeepL closer to standard enterprise SaaS identity management. citeturn30search5turn36search2turn14search0turn36search1turn33search0turn37search2turn37search4

For security, compliance, and deployment control, DeepL currently advertises **GDPR, ISO 27001, SOC 2 Type II, HIPAA**, and in some materials additional attestations; it also documents **BYOK**, **audit logs**, **activity reporting**, **network access restrictions**, and account-support consent/impersonation controls. These capabilities appear across enterprise marketing, security pages, and help articles, with the help center giving the most concrete operational details. citeturn35search3turn35search0turn34search2turn35search1turn37search2

Customization and workflow governance are increasingly central. **Style profiles** can now be shared, assigned, recommended, defaulted, or enforced; **translation memories** can be shared and, in enterprise-flow contexts, updated from translated files; **style rules** can be shared and owned; and **customization admins** can handle much of this without full billing-admin rights. That means DeepL now has a real governance plane for language policy, not just isolated glossary settings. citeturn25search4turn25search6turn15search3turn15search6turn31search9turn25search11

### Skill-ready appendix

**Stable knowledge**

- DeepL’s current top-level portfolio is best modeled as **Translator, Write, Voice, API, and Integrations**, with **Customization Hub** and an **enterprise/admin layer** spanning them.
- **Glossaries, style rules, style profiles, and translation memories** are distinct assets, not synonyms.
- **Voice** includes both **user-facing offers** and an **API**.
- **Marketplace** is a storefront/ecosystem surface, not the translation engine itself.
- **AI connectors** are an access channel into an existing DeepL account via MCP, not a separate core language model product.

**Volatile knowledge**

- Plan names and availability, especially around **API Developer / Growth / Enterprise** and legacy **API Free / API Pro**.
- Supported languages, file formats, session limits, meeting-platform support, and per-surface capability differences.
- Which integrations are currently first-party, partner-built, in beta, or limited to certain plans.
- Exact status and surface availability of **Clarify**, **Translation Flow** subfeatures, and **AI connectors**.
- Security/compliance claims and rollout status for admin controls such as BYOK, audit logs, and network restrictions.

**Required live-verification triggers**

- Any user asks about **current plans, pricing, or packaging**.
- Any user asks **whether a capability is available on a specific surface**.
- Any user asks **which API plan replaces another**, or whether **API Free/API Pro** still exist.
- Any user asks about **supported languages, limits, platforms, or integrations**.
- Any user asks about **beta/GA status**, launch dates after 2025, or current status of Clarify, Translation Flow, or AI connectors.
