# Archived DeepL document register

**Created:** 2026-07-28  
**Status:** Superseded first-pass model; preserved with its original factual
errors.

The current source model and corrected export counts live in
[`private-evidence/deepl-document-register.md`](../../../private-evidence/deepl-document-register.md)
and
[`private-evidence/deepl-document-inventory.json`](../../../private-evidence/deepl-document-inventory.json).
Nothing below is current evidence or process guidance.

This register exists because the recovery pipeline indexed *messages* and never
indexed *documents*. A pasted internal specification and an assistant brainstorm
entered the ledger in the same shape, which is how a fabricated exhibit reached a
published case. This file separates them.

## How to use it

| Tier | Meaning | What it can support |
| --- | --- | --- |
| **B — held** | Full extracted document text is in this repository | Contemporaneous fact, quotable to a line, dated context |
| **C — attested** | The document provably existed — title, date, size, often a Jira or Confluence key — but its contents are unavailable | *That* a formal artifact existed and Mason worked against it. **Never** what it said |

Tier C may never be used to support a claim about a document's contents, a metric,
an approval, or an outcome. It supports one thing: that the work sat inside a
formal product process, named precisely.

Document text is evidence, not publishable material. Several documents name
DeepL colleagues; those names must never reach the public site.

## What this changes

- The corpus is no longer entirely self-authored. Tier B includes a Jira epic, a
  Confluence page, and a UX Writing specification — documents written by the
  organisation, not by Mason about himself.
- Tier C names real Jira and Confluence identifiers (`CAST-`, `DEV-`, `DKH-`,
  `CEX-565`, and the `DM-` experiment canvases). These are precise enough to cite in
  an interview and too specific to have been invented.
- `CAST-DM-1523 Experiment Canvas` is **identified and dated 2025-01-24**, not
  "missing". The achievement ledger's quarantine note should be corrected: the
  canvas is unrecoverable, which is a different status with a different consequence.
- Assistant-generated text is now separable from real documents by data structure
  rather than by reviewer judgement.
